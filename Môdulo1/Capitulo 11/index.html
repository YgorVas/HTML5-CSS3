Imagem Dinâmica

Teste esse site em dispositivos diferentes e veja a diferença no tamanho da imagem.

Para ter imagens de tamanhos diferentes de acordo com a tela, use a tag picture envelopando as tags img e a tag source media type, no parametro src coloque a maior imagem, ACIMA NO CODIGO da tag img adicione a source e no media troque de min para max, e coloque o tamanho da imagem + 50px que voce quer trocar ao diminuir o tamanho da aba.

Áudio no seu site

Use a tag audio, dentro dela coloque a source:src e escolha o caminho e depois especifique o formato. A tag audio vai tentar todas as fontes que você colocar em ordem de acordo com o código, no exemplo abaixo ele tenta o mp3, se nao for ele mostra o texto com opção pra download.

Colocar vídeos no site de forma eficiente

Hospedando diretamente do site

Este vídeo está hospedado diretamente do site, e para você usar é praticamente igual ao audio trocando a tag por video, no entanto tem alguns parametros uteis como width para o tamanho e o poster para a capa do video e claro o controls para começar o video.

Colocando vídeos de uma fonte externa

inserindo vídeos do Youtube

Vá até o vídeo diretamente no youtube, clique em compartilhar e escoolha a opção incorporar que vai gerar o código pronto para adicionar no codigo e editar caso queira.

   

Inserindo Vídeos a partir do vimeo

É uma opção alternativa para o Youtube com mais qualidade, no entanto para upar vídeo é necessário pagar, e é mais seguro caso não queira que o vídeo seja público para outros.
