Como usar o CSS para aplicar em toda a página

Para que seu style no css se aplique a toda página, você vai criar uma tag style no cabeçalho e vai especificar usando o nome da tag da parte da página você quer alterar e abrir cochetes como se fosse uma função, dentro dela você vai estilizar o código com os parametros do style.
