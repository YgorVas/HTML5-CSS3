Usar um documento padronizado .css para o site todo

CSS para quando o seu site tem várias páginas e elas seguem um padrão, é bem melhor você criar um arquivo .css com os styles que você quer em todas as paginas, então ao invés de criar o mesmo cabeçalho para todas as páginas dificultando as modificações, você só cria uma tag link conectando com o arquivo criado .css com os styles padrões para todo o site.

Informações adicionais

Você pode misturar os usos de CSS, mas é de bom tom que você tenha controle sobre o que você está fazendo, isso favorece em muito o CSS EXTERNO, por ser um arquivo padronizado. O em linha é difícil de manter o controle por ser um uso muito local, então só use em casos muito específicos. Já o interno também tem alguns usos para paginas diferentes do todo, mas ainda assim é possível criar outro .css para usar.
