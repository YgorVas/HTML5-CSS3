Usando links externos

Você pode acessar o (usando a tag a) meu canal canal do Youtube. Só que dessa forma substitui a aba do site que você esta no momente. Para evitar isso, usa se os parametros targe="_blank" e o parametro rel="external".

Usando Links Internos

Você não precisa colocar o link inteiro na tag a, se as paginas vierem do mesmo local (nesse caso a pasta do computador).

Usa-se um link que você não quer que o mecanismo de busca identifique como seu, como propagandas, links encaminhando para sites que não sao seus ou complementem seu conteudo.
