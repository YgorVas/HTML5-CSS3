CSS em linha

O CSS em linha você usa o parametro style, e dentro dele você customiza usando outros parâmetros separados por ponto e virgula, mas tudo dentro das aspas do style.

Basicamente você coloca os parâmetros em cada linha que você pretende alterar. No entanto, é ineficiente quando se trata de um site completo, pois ficar modificando tudo linha por linha demanda muito tempo, se tornando ineficiente.
